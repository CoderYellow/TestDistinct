1. FX order gateway: persistence, asynchronous processing, FIX integration, idempotency, failure recovery.
2. Java: concurrency, JVM, executor pools, collections.
3. Spring: Boot, transactions, WebFlux, Reactor, blocking operations.
4. Kafka: consumer groups, offsets, delivery guarantees, replay.
5. SQL and system design: indexes, isolation, outbox, observability.
6. Spoken English: project narrative, ownership, trade-offs, lessons learned.
